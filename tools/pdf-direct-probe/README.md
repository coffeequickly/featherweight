# PDF direct probe

A development experiment, not part of the shipping plugin. Results and limitations: [second experiment](../../docs/PDF-DIRECT-SECOND.md).

## Figma capture

1. `node tools/pdf-direct-probe/build.mjs`
2. Import `build/pdf-direct-probe/manifest.json` in Figma's development plugin menu.
3. Select a node containing an opaque, unfiltered, axis-aligned CROP image. Run **Featherweight PDF Direct Probe**, then choose its exact node/fill button.
4. Save the capture with the explicit button. One JSON contains the original bytes, node/hash/paint metadata, original-resolution reference PDF, q80 Figma baseline, same-resolution JPEG variants, and directly patched PDFs with timings.

The capture recreates a single paint in a temporary rectangle. It does not reproduce surrounding effects, node masks or the product's crop optimization. The temporary frame is removed on completion, error and normal close. Network access is disabled. Never use a "largest cached image" as the target.

## Inspect and reproduce

Requires the repo's Node dependencies, plus Python `pypdf`, `Pillow`, `numpy` and Poppler. Keep private captures in ignored `samples/`.

```sh
node tools/pdf-direct-probe/unpack.mjs capture.json samples/pdf-direct-capture
python3 tools/pdf-direct-probe/bind.py samples/pdf-direct-capture
node tools/pdf-direct-probe/replace-cli.mjs samples/pdf-direct-capture/baseline.pdf samples/pdf-direct-capture/q76.jpg samples/pdf-direct-capture/binding.json samples/pdf-direct-capture/direct-q76.pdf
```

`bind.py` parses the PDF's actual operators, requires one direct image draw and checks its CTM against the captured paint. It writes `binding.json` and the baseline JPEG (`figma.jpg`). The CLI verifies capture hashes. `replace.ts` is shared with the iframe and compares byte snapshots, references, format, exact dimensions and the full alpha mask. Arbitrary documents are outside its contract.

Render reference/baseline/noop and each `direct-qNN.pdf` with `pdftoppm -r 216 -singlefile -png`. `compare.py DIRECTORY` expects these rendered names and produces the metric table and crop contact sheet. A noop is generated by passing `figma.jpg` to `replace-cli.mjs`; this separates PDF serialization savings from image savings.

## Lossless feasibility experiment (native only)

```sh
node tools/pdf-direct-probe/lossless.mjs baseline.pdf lossless.pdf
python3 tools/pdf-direct-probe/verify-lossless.py baseline.pdf lossless.pdf
```

Uses `JPEGTRAN_BIN` or `/opt/homebrew/bin/jpegtran`, with `-strict -copy all -progressive`. Only adopts smaller streams. The native command cannot execute inside Figma; there is no WASM integration yet. Validation compares decoded JPEG pixels, alpha/ICC, page content, text, and all pages rendered at 72dpi. The script expects a report JSON next to the output from `lossless.mjs`.
