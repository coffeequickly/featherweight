> **역사 기록.** 이 문서는 구현 초기(회전 미지원, 613 테스트, 커밋 전)의 검증 기록이다. 현재 결과는

검증 대상: `feat/image-crop`의 커밋 전 작업 트리. Figma 실기 내보내기 2026-09-10, 최종 PDF 대조 2026-09-11.

## 목적과 수정

동일 설정의 기존 출력보다 각 이미지 자리의 픽셀 밀도를 낮추지 않으면서, 보이지 않는 원본 영역을 제외한다. 밀도 유지가 JPEG 재인코딩 결과의 픽셀 동일성을 뜻하지는 않는다.

리뷰에서 재현한 네 결함을 수정했다.

- 원본 밖으로 나가는 CROP 창을 경계로 제한하면 구도가 달라진다. 이런 창과 비유한 값·비대각 변환은 기존 경로로 보낸다.
- FILL의 암묵적 창은 표시 크기가 아니라 노드의 로컬 크기로 계산한다. 비균일 확대에서도 창을 잘못 자르지 않는다.
- 조각의 1px 여백과 출력 양변 반올림을 포함하여 기존 출력의 축별 픽셀 밀도를 만족하는 최소 목표를 구한다. 최대 크기 안에서 만족하지 못하면 기존 경로로 보낸다.
- 조각 이미지 생성 또는 바이트 읽기가 예외를 던져도 준비된 전체 축소본 W₀를 적용하고 용량 통계를 기록한다.

대기 시간 공식, 준비 상태 폴링, 프리셋 및 최소 크기 정책은 변경하지 않았다.

## 자동 검사

수정 전 새 회귀 사례에서 8개 실패를 확인했다. 수정 후 관련 7파일 54테스트 통과, 전체 59파일에서 613테스트 통과·644개 건너뜀. 타입 검사, 린트·Prettier 검사, 빌드 통과.

주요 회귀 검증은 원본 밖 창/비유한 변환, 비균일 확대 FILL, 여백을 포함한 축별 밀도, 조각 생성·읽기 예외의 W₀ 복구다.

## Figma 샘플 A/B

같은 사진을 여러 크롭 창으로 쓰는 900×460 프레임, 균형 설정(1.5×, 최대 1920, 최소 640, JPEG 80%). E는 원본 전체를 보여 주는 자리다.

| 조건 | 기존 PDF | 수정 PDF | 변화 |
| --- | ---: | ---: | ---: |
| E 숨김: 네 자리 모두 일부만 사용 | 593,871 B | 316,343 B | −46.73% |
| E 표시: 전체 사용 자리 포함 | 593,902 B | 593,903 B | 본문 동일, 파일 1 B 차이 |

E 표시 시 페이지 콘텐츠와 이미지 데이터가 동일하고, Poppler 긴 변 1500px 렌더도 픽셀 단위로 동일했다. E 숨김 시 A/B/D는 각각 303²/640²/153², C는 1440×481 이미지가 들어갔다. 클립과 자리 배치는 유지되며 축별 픽셀 밀도는 기존 이상이다. 육안 비교에서 A/B/D의 디테일이 개선되고 C의 뚜렷한 열화는 보이지 않았다.

한 번씩 측정한 플러그인 표시 시간은 E 숨김 기존 1.4초 / 수정 2.3초, E 표시 기존 1.2초 / 수정 1.4초였다. 속도 향상을 검증한 결과가 아니며, 크롭 인코딩과 기존 대기 공식의 비용은 남는다.

## 실제 포트폴리오 A/B

31쪽(1920×1080), 같은 균형 설정. 두 개발 플러그인의 저장된 폰트가 달라 양쪽 모두 모든 텍스트 아웃라인 옵션을 켜서 이미지 경로만 비교했다. 수정본의 테스트용 아웃라인 옵션은 내보내기 후 다시 껐다.

| 항목 | 기존 | 수정 |
| --- | ---: | ---: |
| 파일 크기 | 20,303,647 B (19.36 MiB) | 19,784,967 B (18.87 MiB) |
| 크기 감소 | — | 518,680 B / 2.55% |
| 크롭 적용 | — | 8쪽의 11곳 |

31쪽 모두 페이지 크기와 이미지 배치 수가 같고, 추출 텍스트도 같았다. 이번 비교는 아웃라인 출력이므로 폰트 임베드 품질 검증으로 해석하지 않는다.

PDF의 실제 이미지 크기와 누적 배치 변환으로 각 자리의 양축 밀도를 대조했다. 변경된 11곳의 수정/기존 밀도 비는 약 1.0000~1.1147이다. 최저값 0.999999893은 PDF 변환값의 미세 반올림 수준이다. 나머지 이미지 데이터는 동일하다.

Poppler 긴 변 1200px로 전 페이지를 렌더했다. 23쪽은 픽셀 동일하고, 변경된 1·9·13·18·22·23·24·31쪽을 나란히 육안 확인했을 때 눈에 띄는 구도 변화나 누락은 없었다. 손실 재인코딩으로 변경 영역의 픽셀 값은 다르다. 모든 배율과 렌더러에서의 완전 동일성을 보장하는 검사는 아니다.

수정본 실문서 시간은 37.4초였다. 같은 아웃라인 조건으로 재실행한 기존 버전의 결과 화면 시간을 기록하지 못해 실문서 속도 우열은 판정하지 않는다. 최초 기존 실행의 46.0초는 폰트 처리 조건이 달라 비교에서 제외했다.
