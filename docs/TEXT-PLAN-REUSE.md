# 목표 용량 반복 패스의 텍스트 판정 재사용

2026-09-13 · `codex/image-reuse-verified`의 후속 최적화.

## 구현

목표 용량 모드는 같은 프레임을 기준 패스와 최종 패스에서 반복해 내보낸다. 이미지 설정은
달라지지만 텍스트 내용과 배치는 같으므로, 첫 패스에서 만든 텍스트 소스·승인 결과·숨길 텍스트
노드 순서를 같은 실행의 후속 패스에서 재사용한다. SVG 추출과 UI 폰트 검증은 첫 패스에서만 한다.

일반 내보내기는 두 번째 패스가 없으므로 캐시하지 않는다. 캐시는 내보내기 시작과 성공·오류·취소를
포함한 종료 경계에서 모두 비운다. 원본 텍스트 노드 ID 순서, 텍스트 노드 수, 숨길 노드 색인이
하나라도 맞지 않으면 저장한 판정을 폐기하고 기존 전체 추출·검증 경로로 돌아간다.

## 검증

- 단위 테스트: 같은 구조 재사용, 원본 순서·클론 수·색인 불일치 거절, 실행 경계 초기화.
- 통합 테스트: `exportFrame` 두 패스에서 SVG 추출과 검증이 한 번만 실행되고 두 PDF 패스 모두 원래
  글리프를 숨기는지 확인한다. 클론 구조가 달라지면 전체 추출을 다시 하고, 일반 내보내기는 판정을
  보관하지 않는 것도 확인한다.
- 이전 `perf/reuse` 실험의 31쪽 표본은 텍스트 추출 15.2초 → 7.6초, 전체 83.9초 → 77.7초였다.
  이 수치는 현재 결과에 합산하지 않는다.

### Figma 실기

같은 Figma 데스크톱 문서와 같은 dev 플러그인 ID에서 `피그마 테스트` 페이지의 `포트폴리오`
31쪽을 목표 10MiB로 내보냈다. 생성 파일을 바꾸지 않고, 커밋 `f746f27`의 빌드와 현재 빌드를
같은 manifest 경로에 번갈아 놓아 clientStorage의 폰트와 설정을 공유했다. 두 실행 모두 배율
1.75×·최대 2560px·JPEG 92%를 골랐다.

| 빌드 | 결과 화면 시간 | 실제 파일 |
| --- | ---: | ---: |
| `f746f27` — 텍스트 판정 재사용 전 | 84.1초 | 9,794,240 B |
| 현재 — 텍스트 판정 재사용 | 77.0초 | 9,794,238 B |

한 쌍의 직접 비교에서는 **7.1초, 약 8.4% 단축**됐다. 반복 평균은 아니므로 일반적인 단축률로
확대 해석하지 않는다. 이전 이미지 후보 재사용의 86.2초 → 81.9초 평균과도 더하지 않는다.

출력 검사는 두 파일의 31쪽 전체를 Poppler 72dpi RGB로 렌더했다. 모든 페이지의 픽셀이 완전히
같았고, `pdftotext` 결과와 `pdfimages -list`·`pdffonts` 목록도 같았다. 전체 페이지 접촉판을
육안으로 확인했으며 잘림, 겹침, 깨진 글리프를 발견하지 못했다. 2바이트 파일 크기 차이는 출력
내용 차이가 아니다.

추가로 현재 빌드의 일반 균형 모드는 38.9초였다. 이 경로는 텍스트 판정을 보관하지 않으며, 이전
이미지 재사용 검증의 38.3초와 비슷했다. 목표 용량 경로만 빨라졌다는 구현 범위와도 맞는다.
